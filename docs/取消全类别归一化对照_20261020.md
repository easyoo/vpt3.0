# 取消全类别测试统计量归一化：六组对照

日期：2026-10-20  
代码目录：`/home/jjquan/experiment/visual/audit_mapping`

## 实验目的

检查当前双路融合中的以下类内测试集归一化是否必要：

```python
z_class(M)
z_class(B)
```

本轮不改训练、不改 checkpoint、不改异常图，只改变融合前的归一化方式。

## 三种口径

| 口径 | mapping 归一化 | bank 归一化 | 最终融合归一化 |
|---|---|---|---|
| `class-z`（原正式表） | 整个类别测试像素 z-score | 整个类别测试像素 z-score | 再做整类 z-score |
| `per-image-z` | 每张图单独 z-score | 每张图单独 z-score | 每张图单独 z-score |
| `raw` | 无 | 无 | 无 |

`raw` 是最接近 SubspaceAD、PromptAD、INP-Former 等直接使用原始异常图口径的对照。

其余参数完全固定：

```text
box25
0.5 * (mapping + bank)
Gaussian(k=5, sigma=4)
图像分数 = top-0.5% 像素均值
```

## 结论

1. **完全取消归一化后总体指标仅小幅下降**：六组七项均值下降 `0.05–0.43`。
2. **MVTec4 几乎不变**：`-0.0499`，且方向不确定。
3. **MVTec1/2 的下降很小但统计上较稳定**：类 bootstrap 95% CI 都低于 0。
4. **VisA 三组类别间波动很大**：平均下降约 `0.11–0.43`，但多数类别方向不一致。
5. **逐图 z 不是“取消类内归一化”的中性替代**：它本身显著改变了跨图分数尺度，使图像级指标下降约 2–12 个点。
6. 原审计中“类内 z 造成约 7–10 点虚高”的表述不正确。正确结论应为：
   - 类内 z 确实使用了测试集统计量，属于非 inductive；
   - 但相对于完全 raw 融合，实际总体增益只有约 `0.05–0.43` 个七项均值点，不是接近 9 个点。

## 建议

正式论文若强调单图独立推理，建议报告 `raw` 结果。若保留 `class-z`，需明确标注为 transductive，并且不能再把其相对 raw 的微小差异解释为主要性能来源。

对比时必须保留以下口径差异：

1. SubAD 使用 672 resize、不裁剪、DINOv2 giant、PCA 重构；当前 raw 结果使用 448 测试图与 672 bank 下采样到 448。
2. SubAD 图像分数默认 top-1%；当前结果仍是 top-0.5%。
3. 当前 PRO 使用 `adeval nstrips=200`；SubAD 是 300 个 FPR 等间隔阈值。
4. SubAD 报告五 seed 均值；当前只有单 seed。

因此四项均值只能作为趋势对比，不是严格同实现排名。按当前对比，raw 两路融合没有稳定超过 SubAD：

- MVTec 1/2-shot 约低 `0.49`；
- VisA 1-shot 高 `0.21`，2/4-shot 低 `0.22–0.26`；
- MVTec 4-shot 的名义领先依赖非严格 4-shot 数据，暂不能作为有效胜利。
