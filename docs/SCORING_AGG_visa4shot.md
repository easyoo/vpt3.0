> 代码：[probe_score_agg.py](../probe_score_agg.py)（新增，零训练）
> 权重：`results/visa/vpt35_visa4shot/model_<cls>_35.pth`（vpt3.5 原版，未改动）
> 数据/口径：`/home/jjquan/experiment/visual2/visa_prepared`、4-shot、测试 Resize(448) 不裁剪、
> 1.5×+翻转 2 视图、官方 `adeval`（与交付表完全同口径，`raw_min` 逐位复现基线 75.53）

## 1. 动机

现状打分 `s = 1 − max_k cos(patch, proto_k)`：只信任**一个**最近原型。
* 一个离群/坏原型 → 附近正常像素被误判为正常（漏检）；
* 一个侥幸贴近某个原型的正常像素 → 误判（假高分尾部，正是 P-AP 的病根）。

本实验把"最近邻"换成**一族多原型聚合算子**，全部只改推理打分、不重训。

## 2. 算子定义

`d_1 ≤ d_2 ≤ …` 为 patch 到各原型的距离（`d = 1 − cos`），`d̄` 为**全体原型**距离均值。

| 算子 | 定义 | 直觉 |
|---|---|---|
| `min` | `d_1` | 现状 |
| `kn2/3/5/8` | `mean(d_1..d_k)` | k 近邻平均 |
| `med3` | `median(d_1..d_3)` | 抗单个极端近邻 |
| `har3` | `3/Σ(1/d_i)` | 调和平均 |
| `trim` | `mean(d_2..d_6)` | 丢掉最近的那个 → 抗坏原型 |
| `minmean` | `0.5·d_1 + 0.5·d̄` | 局部 + 全局（加性） |
| **`geom`** | **`√(d_1 · d̄)`** | **局部 × 全局（乘性）** |
| `psoft` | 相对温度 softmin over `d_1..d_8` | 尺度自适应软化 |

侧别：`raw` = 原始特征库（K×1024 个正常 patch，PatchCore 式；4-shot=4096）；
`learn` = 可学习原型集（32 图像自适应 + 32 全局锚点）。

## 6. 结论

1. **单纯"多取几个近邻"无效**（`kn2..kn8`、`med3`、`har3`、`trim` 全在 ±0.2 内，且 P-AP/P-F1 反降）
   —— 与历史上 softmin(A1)、子空间(M27)、邻域聚合(`nb`/`rel_nb`) 的负结果一致。
2. **有效的是"局部 × 全局"的乘性组合 `√(d_1 · d̄)`**：要求一个 patch 不仅离**最近**原型远，
   还要离**整库**都远。它同时压掉两类假高分：侥幸贴近某个原型的正常像素、整幅纹理偏高的正常图。
   → 7 项指标**全部上升**，P-AP +4.24、P-AUPRO +4.21（裸分支口径）。
3. **可学习原型侧换成任何多原型聚合都是负的**（−0.35 ~ −1.92）→ 瓶颈在**原始特征库侧的几何**，
   不在可学习侧；这解释了为什么此前所有"改可学习打分/损失"的尝试都无效。

## 9. 方法学备注（踩过的坑，避免复现时重蹈）

第一版在融合前用了"类内中位数对齐"把变体图的尺度对齐到基线图，
结果 `raw_geom` 报成 **+2.78**；关闭该对齐后同一配置只有 **+2.14**，
而裸分支口径为 **+2.73**。说明**对齐标量会把"两分支相对权重的变化"混进结果**。
本文件 §3 的主表用了无对齐（`c=1`）口径，§4 用裸分支口径给出与缩放无关的确证。
