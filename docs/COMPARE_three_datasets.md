## 四、三条结论

1. **MVTec 4-shot**：融合后 **I-AUROC / P-AUROC / AUPRO 三项均超过表内所有单方法**，与 training-free 的 SubspaceAD 同档。
2. **MVTec 2-shot**：像素级（P-AUROC / AUPRO）已 SOTA，图像级 AUROC 落后 2025–26 一档约 0.5–1.5。
3. **VisA 4-shot**：新打分 + w=0.5 后融合 **四项指标全部反超 SubspaceAD**；
   也是本次打分搜索收益最大的档位（mapping +3.40、融合 +1.60）。
4. 打分改进对三个数据集**全部为正**（mapping：+3.40 / +0.46 / +0.81；融合：+1.60 / +0.27 / +0.19），
   详见 `SCORING_SEARCH_2026-10-13.md`。
